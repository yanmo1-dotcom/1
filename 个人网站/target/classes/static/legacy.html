早期练习 旧的

学习 Java 早期写的练习文件

类型：练习技术：Java · JSON · 配置早期存档

这个文件是干什么的

这是我刚开始学 Java 时写的一些练习和配置文件，作为存档保留下来。

包含的文件

  • JsonExample.java：用纯标准 Java（无第三方库）实现 JSON 的读写示例，用来理解 JSON 解析的底层原理。示例读取 player.json 并操作其中的玩家数据。
  • player.json：示例用到的玩家数据文件，记录了玩家昵称（昊昊）、胜场、总场次和成就（首次胜利、连胜三局、十连击）。
  • new-setting.json：一份 VSCode 编辑器配置，包含工作区信任、联动编辑、缩略图、标尺等设置。
