猜数字 Number Who

带冷却与存档统计的命令行猜数字游戏

类型：命令行程序技术：Java · HTTP · JSON 存档单文件

这个文件是干什么的

这是一个命令行猜数字游戏。系统随机生成 1 到 50 之间的数字，玩家有 8 次机会猜中。游戏带冷却时间防止频繁请求，并且会把每局结果（胜场、总场次、猜测历史）存档到 JSON 文件，下次还能看到统计。

主要功能

  • 数字范围 1-50，最多 8 次尝试
  • 猜测后提示「太大了」或「太小了」
  • 用 AtomicLong 实现冷却时间，防止过于频繁
  • 用 HttpClient 和文件 IO 读写 JSON 存档
  • 统计总场数、胜场、猜测历史，持久化到 save_cth.json

运行方式

单文件，在 number/ 目录下编译运行：

javac -encoding UTF-8 numberwho.java
java number.numberwho
