冰球游戏 Ice Game

一个使用 Java Swing 编写的桌面冰球对战游戏

类型：桌面游戏技术：Java 17 · Swing · Socket构建：Maven

这个文件是干什么的

这是一个冰球（Air Hockey）游戏。玩家控制球拍把球打进对方球门，先得 7 分者获胜。支持两种模式：单人模式由玩家对战电脑 AI，双人模式通过局域网联机对战。

主要功能

  • 单人模式：玩家（左侧）对战电脑 AI（右侧）
  • 双人联机：一名玩家创建房间，另一名玩家通过房主 IP 加入
  • 先得 7 分者获胜；按 R 重新开始，按 Esc 返回菜单
  • 联机时由房主计算球的运动和比分，双方画面保持一致

操作方式

  • 移动鼠标：控制自己的球拍上下移动
  • W / S：也可以控制球拍上下移动
  • 房主点击「创建房间」，把显示的本机 IPv4 地址告诉对方；对方点击「加入房间」输入 IP
  • 默认端口 5050，跨设备需放行防火墙并在同一局域网

运行方式

mvn compile exec:java

或不用 Maven：

javac -encoding UTF-8 -d out src/main/java/com/icegame/*.java
java -cp out com.icegame.Main
