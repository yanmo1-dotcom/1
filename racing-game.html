飞机射击 Racing Game

Java 编写的飞机射击类游戏

类型：桌面游戏技术：Java · Swing · 音效构建：手动编译 / out

这个文件是干什么的

这是一款纵向卷轴飞机射击游戏。玩家驾驶战机消灭敌机，有道具、Boss、波次系统和高分记录。文件按职责拆分成多个类。

主要类与功能

  • GameMain / GamePanel：程序入口与游戏主画面渲染循环
  • PlayerPlane / EnemyPlane：玩家与敌机
  • EnemyManager / WaveManager：敌机生成与波次管理
  • Boss：Boss 战
  • Bullet / Explosion / Particle / FloatingText：子弹、爆炸、粒子、飘字
  • PowerUp / PowerUpType：道具系统
  • Difficulty / EnemyType：难度与敌机类型
  • HighScoreManager：高分记录
  • SoundManager：音效

运行方式

主类 GameMain，在 racing-game/ 目录编译运行：

javac -encoding UTF-8 -d out src/*.java
java -cp out GameMain

源码位于 racing-game/ 目录。
