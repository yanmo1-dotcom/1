A 股实时行情 Sina Stock Web

抓取新浪财经接口的 A 股实时行情网站

类型：Web 应用技术：Spring Boot · 新浪接口 · HTML构建：Maven

这个文件是干什么的

这是一个股票行情网站。后端用 Spring Boot 调用新浪财经的实时行情接口，把 A 股数据展示在网页上，支持搜索股票代码查看实时行情。

主要类与文件

  • SinaStockWebApplication：Spring Boot 启动类
  • controller/StockController：股票查询的 Web 接口控制器
  • StockMarketService：行情业务逻辑
  • util/SinaStockUtil：调用新浪财经接口的工具类
  • StockInfo：股票信息数据模型
  • stock.html：前端页面（A股实时行情中心，带搜索栏）
  • stocks.csv：股票代码列表数据

运行方式

在 sina-stock-web/ 目录下启动 Spring Boot：

mvn spring-boot:run
# 浏览器打开 http://localhost:8080
