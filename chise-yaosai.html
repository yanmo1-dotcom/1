奇斯要塞 Chise Yaosai

Jackal 同类的回合制策略射击游戏

类型：桌面游戏技术：Java · libGDX · Gradle模块：core / desktop

这个文件是干什么的

这是一款基于 libGDX 的策略射击游戏，玩法灵感来自经典桌游《Jackal》（豺狼岛）。在关卡地图上推进，应对不同类型的敌人和武器，含关卡推进和计分。

主要类与功能

  • JackalGame：游戏主类
  • GameWorld / MapCollider / TileMapAssets：世界、地图碰撞、贴图资源
  • LevelManager / ScoreSystem：关卡推进与计分
  • Enemy / Infantry / Jeep / Tank / Turret：敌人类型——步兵、吉普、坦克、炮塔
  • BossArmoredVehicle / POWCamp：Boss 装甲车与战俘营
  • WeaponSystem / Bullet / BulletPool / LaserBeam：武器、子弹池、激光
  • GrenadeState / RocketState / MachineGunState：手榴弹、火箭筒、机枪状态
  • AudioManager：音频

运行方式

Gradle 项目，桌面启动器 com.jackal.desktop.DesktopLauncher。

gradlew desktop:run
