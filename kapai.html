卡牌游戏 Kapai

一款 Roguelike 卡牌游戏（Kapai — Roguelike Card Game）

类型：桌面游戏技术：Java 17 · libGDX · Maven 多模块模块：core / data / ui

这个文件是干什么的

这是一款类似《杀戮尖塔》的 Roguelike 卡牌战斗游戏。玩家用卡牌与怪物战斗，每局地图随机、卡组随机，死亡重来。工程拆成三个 Maven 模块，职责清晰。

模块结构

  • kapai-core：核心逻辑，包含战斗（battle）、卡牌（card）、生物（creature）、效果（effect）等子系统
  • kapai-data：数据层，卡牌与生物的定义、配置
  • kapai-ui：基于 libGDX 的界面与渲染（LWJGL3 桌面启动）

技术栈

  • libGDX 1.12.1 作为游戏框架
  • Lombok 简化实体代码、Jackson 处理 JSON 数据、SLF4J 日志
  • Junit 5 单元测试

运行方式

在 kapai/ 目录下用 Maven 构建，运行 UI 模块（LWJGL3 桌面启动器）。

mvn -pl kapai-ui -am package
java -jar kapai-ui/target/*.jar
