班级 API 服务

基于 Token 权限的班级学生查询服务

类型：后端服务技术：Java · Token 鉴权构建：VS Code Java

这个文件是干什么的

这是一个演示「权限控制」的小型后端服务。不同的 Token 代表不同身份，查询班级学生时只能看到自己权限范围内的数据。比如男生 Token 只能看到男生的信息，管理员 Token 能看到所有人，无效 Token 被拒绝。

主要类与功能

  • Main：程序入口，用不同 Token 测试查询结果
  • ClassApiService：对外提供的查询接口，根据 Token 过滤数据
  • ClassDataStore：班级数据存储
  • Student：学生数据模型
  • App：辅助入口

权限示例

  • token_male_only：只能看男生
  • token_female_only：只能看女生
  • token_leader_admin：管理员，看所有人
  • hacker_token：无效，被拒绝

运行方式

主类 Main，直接运行即可看到不同 Token 的查询输出：

java -cp src Main

源码位于 api/ 目录。
