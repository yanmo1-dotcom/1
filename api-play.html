班级 API 服务 · 在线演示

基于 Token 权限的班级学生查询 · 输入不同 Token 看到不同范围数据

原作：api/纯前端模拟6 条学生数据

1. 输入 Token 查询

token_male_only（只看男生） token_female_only（只看女生） token_leader_admin（管理员/全部） hacker_token（无效）

模拟 GET /api/students?token=xxx 接口。管理员 Token 返回全部 6 人，男生/女生 Token 各返回 3 人，无效 Token 返回 403。

点击「查询」查看返回的 JSON…

这是后端存储的全部学生数据。API 返回时只输出 id、name、gender 三个字段。
