命令行聊天室 · 在线演示

纯 Java Socket 多房间聊天室 · 本地模拟多用户终端

原作：chat-room-java/端口 8888（模拟）多房间·私聊·好友

可用命令

/help 帮助 · /list 在线用户 · /room list 房间列表
/create <房名> [密码] 创建房间 · /join <房名> [密码] 加入房间
/leave 回到 public · /friend add <用户> 加好友 · /whisper <用户> <内容> 私聊
exit 断开 · 直接输入文字即房间内发言

提示：可在上方切换"当前用户"模拟多终端交互。
