命令行聊天室 Chat Room

纯 Java Socket 实现的多房间命令行聊天室

类型：网络应用技术：Java · Socket · 多线程构建：Maven

这个文件是干什么的

这是一个纯 Java 实现的命令行聊天室，不依赖 Web。服务端监听端口，客户端通过 Socket 连接，支持多聊天房间。体现了网络编程、多线程并发、协议设计的能力。

主要类与功能

  • App：程序入口
  • server/ChatServer：服务端，监听连接并分发到房间
  • server/ClientHandler：处理单个客户端连接的线程
  • server/Room：聊天房间，管理房间内的成员与消息广播
  • server/LoggerService：日志服务，记录聊天记录
  • client/ChatClient：客户端，连接服务端收发消息
  • Message：消息数据模型

运行方式

在 chat-room-java/chat-room/ 目录下用 Maven 打包，分别启动服务端和客户端：

mvn package
java -cp target/chat-room-1.0-SNAPSHOT.jar com.chatroom.server.ChatServer
java -cp target/chat-room-1.0-SNAPSHOT.jar com.chatroom.client.ChatClient
