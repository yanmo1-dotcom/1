# 我的世界 (Minecraft 2D)

使用 Java Swing 开发的 2D 侧视视角体素沙盒游戏，致敬经典的 Minecraft。

## 项目结构

```
wodeshijie/
├── src/                    # 源代码
│   ├── Main.java           # 程序入口
│   ├── GameFrame.java      # 主窗口
│   ├── GamePanel.java      # 游戏主面板（渲染、输入、游戏循环）
│   ├── World.java          # 世界生成与管理
│   ├── Player.java         # 玩家物理与控制
│   ├── Camera.java         # 相机跟随系统
│   ├── Inventory.java      # 物品栏/快捷栏
│   └── BlockType.java      # 方块类型定义
├── bin/                    # 编译输出（class文件）
├── .vscode/
│   ├── launch.json         # VSCode 运行配置
│   └── tasks.json          # VSCode 编译任务
└── README.md
```

## 环境要求

- JDK 8 或更高版本（开发使用 JDK 26）
- VS Code（推荐安装 Extension Pack for Java 插件）

## 运行方式

### 方式一：VS Code 中运行（推荐）

1. 用 VS Code 打开 `wodeshijie` 文件夹
2. 确保安装了 Java 扩展包
3. 打开 `src/Main.java`，点击右上角的运行按钮，或按 `F5`
4. 也可以使用 `Ctrl+Shift+B` 编译，然后 `Ctrl+Shift+P` → "Run Task" → "运行游戏"

### 方式二：命令行编译运行

```bash
# 进入项目目录
cd wodeshijie

# 编译
javac -encoding UTF-8 -d bin src/*.java

# 运行
java -cp bin Main
```

## 游戏特性

- **程序化地形生成**：使用多层正弦波生成自然起伏的地形，包含草地、沙滩、雪山
- **多种方块类型**：草方块、泥土、石头、木头、树叶、沙子、水、木板、煤矿石、铁矿石、钻石矿石、玻璃、砖块、基岩、雪块、火把
- **矿石系统**：煤、铁、钻石按深度分布，越深越稀有
- **树木生成**：草地上随机生成带树冠的树木
- **物理系统**：重力、跳跃、碰撞检测、摩擦力
- **方块破坏**：不同方块有不同硬度，破坏后自动收入背包
- **方块放置**：支持点击方块侧面放置，自动检测碰撞避免卡住玩家
- **物品栏**：9格快捷栏，初始提供多种建筑方块
- **相机跟随**：平滑跟随玩家移动
- **无限世界**：512×128 格的广阔世界
- **昼夜视觉**：天空渐变、太阳、云朵、水波纹动画

## 技术要点

- 纯 Java Swing 实现，无第三方依赖
- 固定时间步长游戏循环（60 FPS）
- AABB 碰撞检测与逐像素推回
- 视口裁剪渲染（只绘制可见方块）
- 基于种子的伪随机世界生成
