Web 聊天室（Token 版）

带用户登录与数据库存储的网页聊天室

类型：Web 应用技术：Spring Boot · WebSocket · H2/MySQL构建：Maven

这个文件是干什么的

这是一个完整的网页聊天室后端 + 前端项目。用户登录后获得 Token，消息持久化到数据库。除了聊天，还内置了后台管理、移动端页面和五子棋小游戏页面。

主要功能与文件

  • WebChatApplication：Spring Boot 启动类
  • TokenManager：登录 Token 的生成与校验
  • static/index.html：桌面版聊天页面（窄屏自动跳转移动版）
  • static/mobile.html：移动版聊天页面
  • static/admin.html：后台管理页面
  • static/gomoku.html：五子棋游戏页面
  • schema-h2.sql / schema-mysql.sql：H2 与 MySQL 两种数据库建表脚本
  • users.json：用户数据

运行方式

在 web-chat-room/ 目录下用 Maven 启动 Spring Boot，然后浏览器访问本地服务。

mvn spring-boot:run
# 浏览器打开 http://localhost:8080
