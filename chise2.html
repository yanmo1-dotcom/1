奇斯 2 Chise2

奇斯要塞的升级版，新增网页运行版本

类型：桌面 / 网页游戏技术：Java · libGDX · GWT模块：core / desktop / web

这个文件是干什么的

这是「奇斯要塞」的第二个版本，核心玩法相同（Jackal 风格策略射击）。最大的区别是新增了 Web 网页版本：通过 GWT 把 Java 代码编译成 JavaScript，让游戏可以直接在浏览器里运行，无需安装。

与奇斯要塞的区别

  • 新增 web 模块（HtmlLauncher + GWT 配置），支持浏览器运行
  • 保留 desktop 桌面版本
  • 核心 core 与奇斯要塞结构一致（敌人、武器、关卡等）

运行方式

桌面版：

gradlew desktop:run

网页版（编译后在浏览器打开）：

gradlew web:superDev

源码位于 chise2/ 目录。
