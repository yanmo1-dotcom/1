# 丐版泰拉瑞亚 · Terraria Lite

一个用 **JDK 26 + 纯 Java Swing** 编写的横版沙盒游戏，复刻泰拉瑞亚核心玩法闭环：**挖掘 → 收集 → 建造 → 合成 → 战斗**。无任何第三方依赖，一个 `run.bat` 即可运行。

---

## 玩法总览

| 能力 | 说明 |
|---|---|
| 挖掘 | 鼠标左键瞄准方块按住，按挖掘进度破坏方块，掉落物进入背包 |
| 放置 | 鼠标右键把选中方块放回世界（需与已有方块相邻、不卡在角色身上） |
| 合成 | 放置「工作台」并靠近，按 `E` 打开合成面板：木剑 / 铜剑 / 铁剑 / 木弓 / 铁弓 / 箭矢 / 可疑眼球 / 火把 / 工作台 |
| 装备武器 | 选中武器点右键装备；近战剑（木12 → 铜16 → 铁20，挥砍带剑光弧光）；**远程弓（木弓8 / 铁弓13，右键搭弓左键射箭，消耗箭矢，抛物线+重力）** |
| 战斗 | 左键点击敌人挥剑（伤害+击退）/ 射箭（直线+重力、命中溅粒子）；**挥砍带剑光弧光、命中溅粒子、伤害数字上飘**；接触敌人受伤 |
| 敌人 | 史莱姆（凝胶）；夜晚刷新僵尸（腐肉、伤害更高） |
| Boss | **克苏鲁之眼**：夜晚右键使用「可疑眼球」（腐肉×6+铁×3 合成）召唤；飞行追踪 + 周期冲刺，半血狂暴，顶部 Boss 血条；击败掉落大量铜铁 + 腐肉 + 生命水晶 |
| 生命 | 击杀敌人概率掉落红心（+20HP）；地下探索「生命水晶」可永久提升生命上限 |
| 背包 | 按 `B` / `Tab` 打开**完整背包**（热键栏 10 格 + 主背包 20 格）；**鼠标拖拽移动、拖出面板丢弃到世界、一键整理**（合并同类按 id 排序）；拾取/合成自动入包 |
| 联机 | 主菜单「多人游戏」创建主机 / **局域网房间列表一键加入** / 手动输 IP；**游戏内 Enter 聊天**（全服广播），最多 5 人 |
| 昼夜 | 150 秒昼夜循环，夜晚变暗、怪物更多，火把可照亮周围 |
| 地形 | **生物群系**：沙漠 / 雪原 / 丛林 / 森林四大区（各有专属地表方块与植被），分段平原 / 丘陵 / 山地平滑衔接，出生点整片平原 |
| 性能 | 方块层**滚动缓存**渲染（摄像机移动只重绘新露出的行列）+ 光照仅遍历可见范围，HUD 右上角实时 FPS |
| 菜单 | 主菜单（开始/多人/操作说明/退出）、游戏内 Esc 暂停菜单、操作说明页 |
| 存档 | F5 保存、F9 读档（兼容旧存档）、F6 生成新世界 |

## 操作方式

| 按键 | 功能 |
|---|---|
| `A` / `D`（或方向键） | 左右移动 |
| `空格` / `W` / `↑` | 跳跃（松开可提前终止，控制跳高） |
| 鼠标左键 | 按住挖掘方块 / 点击敌人挥剑攻击 / 拉弓时射箭 |
| 鼠标右键 | 放置选中方块 / 使用物品（装备武器、用生命水晶、夜晚召唤 Boss、合成凝胶块、**装备弓后拉弓**） |
| `E` | 靠近工作台时打开合成面板 |
| `B` / `Tab` | 打开 / 关闭完整背包 |
| `1`-`0` 或滚轮 | 切换物品栏 |
| `Enter` | 联机时打开聊天输入（再次 Enter 发送，Esc 取消） |
| `Esc` | 打开 / 关闭暂停菜单 |
| `F5` / `F9` / `F6` | 保存世界 / 读档 / 生成新世界 |
| 主菜单「多人游戏」 | 创建主机 / **刷新局域网房间列表一键加入** / 输入 IP 加入主机（默认端口 25565） |

> 挖掘需在武器攻击范围内（约 6.5~7.5 格）；挖掘进度条显示在方块上方。

## 联机多人（HOST / CLIENT）

采用**主机权威**模型：主机裁决世界方块与敌人，客户端同步世界种子后各自本地模拟自己。

- **创建主机**：主菜单 →「多人游戏」→「创建主机」，本机即为主机（默认端口 25565），**自动向局域网广播房间**，等待玩家加入
- **房间列表**：主菜单 →「多人游戏」→「刷新房间」，通过 **UDP 广播发现局域网主机**（显示主机名 + IP:端口），点击房间一键加入
- **加入游戏**：主菜单 →「多人游戏」→「加入游戏」，输入主机 IP 即可，收到主机世界种子后自动同步地图
- **聊天**：联机中按 `Enter` 输入消息、再按 Enter 发送，全服广播（含主机，左下角显示聊天记录）
- **同步内容**：玩家位置/血量/武器（每 100ms 广播，远端平滑插值）、方块挖掘与放置（增量事件）、敌人状态（主机模拟、客户端渲染，含 Boss）、击杀掉落与回血
- **主机权威**：主机窗口右上角显示玩家列表与血量；最多 5 人同场
- 命令行快速联机（自动化/测试用）：
  ```powershell
  java -cp out tailai.Main --host 25565
  java -cp out tailai.Main --join localhost 25565
  ```

## 游戏内容

- **程序化世界**：800 × 240 格横版地图，**四大生物群系（森林 / 沙漠 / 雪原 / 丛林，按 x 大区分配、出生点固定森林）**、分段平原 / 丘陵 / 山地地表（出生点整片压平）、草/土/石分层、铜/铁矿脉（深度跟随地表）、地下洞穴、群系专属植被（森林树 / 仙人掌 / 针叶树 / 丛林大树）、地下的生命水晶
- **方块**：草皮、泥土、石头、铜矿、铁矿、木头、树叶、凝胶块、火把、工作台、生命水晶 + **沙子 / 雪块 / 冰块 / 仙人掌 / 丛林草皮**
- **物品**：方块类 + 凝胶 / 腐肉（材料）+ 木剑 / 铜剑 / 铁剑（近战）+ **木弓 / 铁弓 / 箭矢（远程）** + **可疑眼球（Boss 召唤物）** + 生命水晶
- **合成配方**（工作台面板）：木剑(木头×8)、铜剑(铜矿×10+木头×4)、铁剑(铁矿×10+木头×4)、**木弓(木头×10)、铁弓(铁矿×10+木头×6)、箭矢×5(木头×1+石头×1)、可疑眼球(腐肉×6+铁×3)**、火把×2(木头×1+凝胶×1)、工作台(木头×10)；背包右键凝胶 2→1 凝胶块
- **敌人**：史莱姆（白天/夜晚）、僵尸（夜晚，HP45/伤害14）、**克苏鲁之眼 Boss（HP1000/伤害20，飞行+冲刺+狂暴，顶部血条，掉落铜铁/腐肉/生命水晶/召唤物）**
- **背包**：热键栏 10 格 + 主背包 20 格，B/Tab 打开，**拖拽移动（同类合并/异类交换）、拖出面板丢弃为掉落物、一键整理**
- **菜单**：主菜单、暂停菜单、操作说明页，全部鼠标操作

## 手感调优（对照原版）

| 参数 | 旧版 | 现版（原版向） |
|---|---|---|
| 最大移动速度 | 235 px/s（~14.7 格/s） | **150 px/s（~9.4 格/s）** |
| 加速度 | 2100 | **1300（地面）/ 700（空中）** |

| 重力 | 900 | **850** |
| 最大下落 | 720 | **620** |

整体节奏更沉稳：移动有惯性、跳跃高度受限、落地更稳，更接近原版 Terraria 的手感。

## 性能与渲染（滚动缓存）

旧版渲染每帧都会在摄像机发生任何微小位移时**全量重建整屏方块**，移动时明显卡顿。现改为：

- **方块层滚动缓存**：方块图像缓存在一张覆盖视口+1 边的大图里；摄像机跨过整格时才**平移旧内容并只重绘新露出的列/行**；挖掘/放置方块时才按改动计数局部重绘。
- **光照限定可见范围**：火把光晕不再每帧扫描全图 19 万格，仅遍历视口附近格子；暗幕光照循环仅在夜晚/地下执行。
- 实测移动 / 持续攻击时 **FPS 稳定在 170~210**（HUD 右上角实时显示）。

## 已知限制（丐版取舍）

- 联机为主机权威模式：无断线重连；房间发现依赖局域网 UDP 广播（跨网段/公网需手动输 IP）
- 玩家物品栏各自独立，不做交易/共享
- 合成仅在靠近工作台时可用，无全局制作栏
- Boss 仅克苏鲁之眼一种，无后续 Tier 装备 / 护甲 / 饰品
- 聊天为纯文本（无表情/颜色），客户端需切英文输入法打字
- 无 NPC、完整的生命值之外的资源系统
- 无音效 / 音乐
- 存档为二进制单文件 `world.sav`（v2，兼容 v1，不含背包/玩家物品）
